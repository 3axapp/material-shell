# Функциональные требования

Что расширение должно делать с точки зрения пользователя. Список собран из
[README](../../README.md), схем настроек в `schemas/`, устройства кода
([ARCHITECTURE.md](ARCHITECTURE.md)) и исправленных issue форка. Используйте
его как чек-лист регрессий: после порта на новую версию GNOME, после правок
фокуса, темы и состояния.

У каждого требования есть колонка «Проверка»:

- **авто** — есть тест в `tests/` (`make test`, `make test-shell`);
- **вручную** — автотеста нет, проверяется в настоящей сессии или во
  вложенном шелле.

Где README и код расходятся, правильным считается код. Например, сочетания
клавиш задаёт схема `bindings`, а не таблица в README (см. раздел 7).

## 1. Включение и выключение

| ID | Требование | Проверка |
|----|------------|----------|
| FR-1.1 | Расширение загружается на версии GNOME Shell, указанной в `metadata.json` (сейчас `51`), без `JS ERROR` в журнале. | вручную (лог `EXTENSION LOADED`) |
| FR-1.2 | Если шелл ещё стартует, интерфейс строится после `startup-complete`, а до того показывается заставка. | вручную |
| FR-1.3 | Шелл, запущенный без мониторов, не падает: расширение ждёт появления монитора и только потом строит интерфейс ([#12](https://github.com/3axapp/material-shell/issues/12)). | авто: `tests/shell/no-monitor-at-start.test.js` |
| FR-1.4 | При блокировке экрана расширение только прячет панель. После разблокировки окна, столы и плитки остаются на месте, ничего не пересоздаётся. | вручную |
| FR-1.5 | После полного выключения расширения шелл выглядит и ведёт себя как обычный GNOME: панели, плитки и заглушки Material Shell исчезают, окна остаются открытыми и видны как обычные, работают обзор шелла и его анимации, а настройки GNOME, которые расширение меняло, возвращаются к прежним значениям (FR-10.3). В журнале нет `JS ERROR`. | вручную |
| FR-1.6 | Если пропадает последний монитор, шелл продолжает работать без `JS ERROR` от расширения, а окна остаются на своих столах. Окно, открытое без мониторов, получает вкладку в панели задач. Когда монитор возвращается, интерфейс восстанавливается ([#22](https://github.com/3axapp/material-shell/issues/22)). | авто: `tests/shell/last-monitor-unplugged.test.js` |
| FR-1.6 | Несовместимые расширения не включаются, пока работает Material Shell: `desktop-icons@csoriano`, `ubuntu-dock@ubuntu.com`, `dash-to-dock@micxgx.gmail.com`, `ding@rastersoft.com`, `pop-shell@system76.com`, `improved-workspace-indicator@michaelaquilina.github.io`. | вручную |
| FR-1.7 | Загрузка идёт плавно: заставка с эмблемой расширения, затем GNOME с работающим расширением. Ничего не дёргается и не мерцает, элементы не появляются и не пропадают по ходу. То же при появлении нового стола ([#15](https://github.com/3axapp/material-shell/issues/15)). | вручную; частично авто: `tests/shell/no-menu-flash-at-start.test.js`, `tests/shell/no-menu-flash-on-new-workspace.test.js` |

## 2. Пространственная модель: столы и окна

| ID | Требование | Проверка |
|----|------------|----------|
| FR-2.1 | Стол — строка, окна — ячейки в ней. Новое окно встаёт в конец строки активного стола (или подходящего, если оно восстанавливает заглушку, FR-9.3). | вручную |
| FR-2.2 | В конце списка всегда есть один пустой стол. Пустые столы, кроме последнего, удаляются. | вручную |
| FR-2.3 | Столы переключаются только на основном мониторе. У каждого внешнего монитора свой стол со своей раскладкой. | вручную |
| FR-2.4 | Иконка стола в панели определяется категорией приложений в нём, либо иконками приложений, в зависимости от настройки `panel-icon-style` (FR-8.5). | вручную |
| FR-2.5 | Расширение не берёт под управление окна с `wm_class` из `windows-excluded`, с ролью из `roles-excluded`, окна «поверх всех» и окна, тип которых не NORMAL, DIALOG, MODAL_DIALOG или UTILITY. | вручную |
| FR-2.6 | Диалог не получает своей плитки: он прикрепляется к плитке родительского окна (по `transient_for`, тому же pid или приложению). | вручную |
| FR-2.7 | Закрытие последнего окна в плитке удаляет плитку. Если приложение сразу открывает новое окно (диалог закрылся — открылось главное), плитка его подхватывает. | вручную |
| FR-2.8 | Закреплённая плитка после закрытия окна остаётся заглушкой приложения. Из заглушки приложение можно запустить заново. | вручную |
| FR-2.9 | Незакреплённая плитка, для которой запустили приложение, закрывается, если окно не появилось за 5 секунд. Пока открыт диалог polkit, отсчёт стоит. | вручную |

## 7. Сочетания клавиш

Все сочетания переназначаются в окне настроек (вкладка Hotkeys). Значения по
умолчанию — из схемы `bindings`:

| Действие | По умолчанию |
|----------|--------------|
| Стол выше / ниже / последний | `Super+W` / `Super+S` / `Super+Z` |
| Стол 1–10 | `Super+1` … `Super+0` |
| Окно слева / справа | `Super+A` / `Super+D` |
| Лаунчер приложений | `Super+X` |
| Закрыть окно | `Super+Q` |
| Сдвинуть окно влево / вправо | `Super+Left` / `Super+Right` |
| Окно на стол выше / ниже | `Super+Up` / `Super+Down` |
| Окно на стол 1–10 | `Shift+Super+1` … `Shift+Super+0` |
| Фокус на монитор (4 направления) | `Alt+Super+стрелка` |
| Окно на монитор (4 направления) | `Shift+Super+стрелка` |
| Размер окна (4 направления) | `Ctrl+Super+стрелка` |
| Следующая / предыдущая раскладка | `Super+Space` / `Shift+Super+Space` |
| Скрыть/показать интерфейс | `Super+Escape` |
| Конкретная раскладка | не назначено |

| ID | Требование | Проверка |
|----|------------|----------|
| FR-7.1 | Каждое сочетание из таблицы выполняет своё действие. | вручную |
| FR-7.2 | Сочетания GNOME, которые совпадают с сочетаниями расширения, на время работы отключаются и возвращаются при выключении. | вручную |
| FR-7.3 | Сочетание, изменённое в настройках, начинает работать без перезапуска шелла. | вручную |
| FR-7.4 | `Super+Escape` прячет и показывает панели («режим без интерфейса»); состояние переживает перезаход. | вручную |

## Минимальный ручной прогон

Когда некогда проходить весь список (например, после порта на новую версию
GNOME), проверьте хотя бы это:

1. FR-1.1 — расширение загрузилось без `JS ERROR`.
2. FR-3.1, FR-3.6, FR-4.1 — переключение столов с окном и без; ввод в
   Wayland-клиенте после переключения и после закрытия окна.
3. FR-2.3, FR-5.4 — несколько мониторов, если есть.
4. FR-8.4, FR-8.8 — смена темы.
5. FR-11.1, FR-11.4 — окно настроек.
6. FR-9.2 — восстановление после перезахода.
